# ExamFlow

ExamFlow는 고등학교 중간·기말고사 시간표를 만드는 웹앱입니다. 학생마다 공통 과목과 선택 과목의 조합이 다른 점을 반영해, 같은 날 시험이 몰리거나 연속 교시에 이어지는 부담을 줄입니다.

[ExamFlow 열기](https://minpk0625-max.github.io/examflow-website/)

## 사용 방법

1. **과목·학생 자료 → 시험 과목 선택**에서 학년별 시험 과목을 고릅니다. 해당 학년이 모두 응시하면 **학년 공통**, 일부 학생만 응시하면 **학생 선택**으로 설정합니다.
2. 학년별 학생 수를 입력하고 **맞춤 엑셀 양식**을 내려받습니다. `학생별수강` 시트에서 학생 한 명을 한 행에 입력하고, 응시 과목은 `1`, 미응시 과목은 `0`으로 표시합니다. 학년 공통 과목은 해당 학년 학생에게 자동으로 `1`이 채워집니다.
3. 작성한 엑셀 파일을 불러옵니다. 과목별 인원 합계만으로는 어떤 학생이 여러 과목을 함께 응시하는지 알 수 없어 학생별 자료가 필요합니다.
4. **시험 설정**에서 시험 날짜와 교시를 지정한 뒤 시간표를 생성합니다. 결과는 시간표 또는 달력으로 확인하고 엑셀로 저장할 수 있습니다.

## 시간표 계산 기준

| 순서 | 기준 |
| --- | --- |
| 필수 조건 | 같은 학생이 응시하는 두 과목을 같은 교시에 배치하지 않습니다. |
| 1순위 | 한 학생이 하루에 치르는 최대 시험 수를 줄입니다. |
| 2순위 | 같은 날 두 과목 이상을 치르는 학생 수와 그런 학생별 날짜 수를 줄입니다. |
| 3순위 | 같은 날 바로 이어지는 교시에 시험을 보는 학생 수와 연속 시험 횟수를 줄입니다. |

월요일 마지막 교시와 화요일 첫 교시처럼 날짜가 다르면 연속 시험에 포함하지 않습니다. 프로그램은 주어진 시간 안에 여러 배치를 비교해 가장 좋은 결과를 제시합니다.

## 과목 목록과 데이터 처리

2022 개정 교육과정의 고등학교 보통교과 155개를 기본 목록으로 제공합니다. 학교에서 실제로 시험을 치르는 과목만 선택하며, 목록에 없는 과목은 직접 추가할 수 있습니다. 교육과정의 과목 분류와 학교의 응시 방식은 각각 설정할 수 있습니다.

엑셀 읽기와 시간표 계산은 브라우저에서 이루어집니다. [저장소](https://github.com/minpk0625-max/examflow-website)에서 `index.html`을 내려받으면 인터넷 연결 없이도 사용할 수 있습니다.

과목 목록 출처는 [부산광역시교육청 고교학점제 지원센터](https://home.pen.go.kr/hscredit/cm/cntnts/cntntsView.do?cntntsId=3817&mi=17411)와 [경기도교육청 과목 개설 길라잡이](https://www.goe.go.kr/resource/goe/na/bbs_2675/2026/02/b1f199d4-819f-4f84-9e8b-092e66eeddd0.pdf)입니다.
